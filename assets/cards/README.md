# Ilustrações

Use o ID de cada carta definido em `deck.js`, sem alterar o nome-base. A aplicação aceita PNG, WebP, JPG e JPEG; envie seus PNGs diretamente. Para o verso, use `back.png` ou `back.webp`. As imagens devem ter proporção vertical 2:3, sem texto nem moldura. Quando uma ilustração estiver ausente, a aplicação exibe a arte geométrica provisória. Consulte ../../prompts/README.md.
