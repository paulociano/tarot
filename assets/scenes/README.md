# Ambientes ARCANA Cinematic

Imagens opcionais em formato panorâmico 16:9. Use PNG ou WebP com os nomes abaixo. A aplicação carrega a pintura quando existe e mantém o fundo anterior enquanto estiver ausente. A versão otimizada gera WebP de até 1920 × 1080 automaticamente.

| Arquivo | Ambiente |
|---|---|
| portal.png | Início |
| santuario.png | Tiragem |
| biblioteca.png | Baralho |
| observatorio.png | Carta do dia |
| grimorio.png | Diário |

Não inclua textos, interfaces, cartas desenhadas, marcas ou molduras. Mantenha espaço negativo escuro para a leitura. Os arquivos de criação artística não são distribuídos na interface.
